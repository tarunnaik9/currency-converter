# CURRENCY CONVERTER

Welcome to the Currency Converter! This web application is designed to make currency conversions quick and easy. Using HTML, CSS, and JavaScript, the tool allows users to convert amounts between various currencies with real-time rates. It's a practical project to enhance my web development skills and deepen my understanding of APIs and user interface design.
# Objective

To develop a user-friendly web application that allows users to convert amounts between USD, EUR, GBP, JPY, and INR using real-time exchange rates. The project focuses on showcasing practical web development skills using HTML, CSS, and JavaScript while ensuring simplicity and efficiency in currency conversion.

# Features 
1.Users can input the amount they want to convert between supported currencies.

2.Users can select the source currency and the target currency from dropdown menus (USD, EUR, GBP, JPY, INR)

3.Fetches the latest exchange rates for accurate and up-to-date currency conversions.

4.Displays the converted amount immediately after user input and selection.

5.Simple layout with easy-to-use input fields and responsive buttons for smooth interaction.
